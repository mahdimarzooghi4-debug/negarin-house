# نگارین هنرمند برای اندروید

این پوستهٔ اندرویدی، نسخهٔ موبایل هنرمند را در WebView تمام‌صفحه باز می‌کند. برنامه به اینترنت نیاز دارد و در حال حاضر صفحهٔ هنرمند نگارین روی Stage را باز می‌کند.

## ساخت APK آزمایشی

پس از تأیید مجوزهای Android SDK، از GitHub Actions با اجرای دستی workflow «Build Android APK» فایل `app-debug.apk` ساخته می‌شود. APK آزمایشی با کلید debug امضا می‌شود و برای نصب دستی روی دستگاه مناسب است؛ انتشار در Play Store به امضای release جداگانه نیاز دارد.

شناسهٔ برنامه: `com.negarin.artist`
